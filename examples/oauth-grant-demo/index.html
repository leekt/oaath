OAAth Grant demo

Registering this demo with the issuer…

1. Request permission

Sign in through the OAAth portal and approve one tiny Grant: this page's session key may make zero-value calls with selector to , at most twice per chain, for one hour.

2. Fund the account for gas

Account does not need to exist yet: the first operation deploys it. There is no paymaster, so send it testnet ETH for gas.

3. Send the covered call

One UserOperation deploys the account, installs the permission in enable mode and makes the call. It is sent once; if an answer is lost the page only observes.
